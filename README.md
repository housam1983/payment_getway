# Payment Gateway

This repository contains a simple example of how to create a payment using the [Moyasar](https://moyasar.com/) API.

## Example

The `moyaser_payment.py` script demonstrates how to send a payment request using Python and the `requests` library. Update the `API_KEY` constant with your Moyasar secret key before running the script.

```bash
python3 moyaser_payment.py
```
